## Lineage

CeylonDemon is built on the **NARC Engine** codebase by the same author, used
under GPLv3 — board representation, move generation, search, time management
and Lazy SMP. The **Resonance** evaluator is original to CeylonDemon.

## 1. Search techniques

The search implements standard, long-published techniques that are the shared
inheritance of computer chess. None were invented for this project:

Principal variation search · aspiration windows · null-move pruning with
verification search · late move reductions · singular extensions · ProbCut ·
razoring · reverse futility pruning · futility pruning · late move pruning ·
SEE pruning of quiet moves · delta pruning in quiescence · internal iterative
reductions · killer moves · counter-moves · history heuristic with gravity ·
threat-aware history · continuation history · capture history ·
pawn-structure correction history · expected cut-node tracking ·
TT was-PV flag · MVV-LVA ordering · static exchange evaluation (swap-list
form) · magic bitboards · Zobrist hashing · Lazy SMP.

Specific attributions:

- **Singular extensions** — Anantharaman, Campbell and Hsu (Deep Thought, 1988).
- **Null-move pruning** — Beal (1989); adaptive R after Donninger (1993).
- **ProbCut** — Michael Buro (1995), originally for Othello.
- **PVS / NegaScout** — Pearl (1980); Reinefeld (1983).
- **Lockless transposition table** (storing `key ^ data` so a torn read under a
  race is detected as a key mismatch) — Robert Hyatt.
- **xorshift\*** PRNG — George Marsaglia's xorshift family, Vigna's multiplier.
- **FNV-1a** hash, used in `archHash()` — Fowler, Noll and Vo.

Threat-aware history, correction history, was-PV reductions and cut-node
reductions are techniques popularised in open-source engines over recent years;
CeylonDemon's implementations were written for this project and tuned by its
own match testing.

## 2. NNUE inference design — Stockfish lineage, acknowledged

Resonance's *feature architecture* is original (§4). Its *quantisation and
inference scheme* follows the design published by the Stockfish project, which
the open engine ecosystem has broadly converged on:

| Element | Value | Origin |
|---|---|---|
| Weight scale bits | 6 | Stockfish `WeightScaleBits` |
| Output scale | 16 | Stockfish `OutputScale` |
| Activation clip | `[0, 127]` | Stockfish NNUE |
| Output buckets | 8 | Stockfish `LayerStacks` |
| Pairwise L1 product, `>> 7` | — | Stockfish SFNNv5+ |
| Clipped ∥ squared-clipped concat | — | Stockfish SFNNv5+ |
| Horizontal king mirroring | — | Stockfish HalfKAv2\_hm |

These are architectural ideas and numeric scales rather than expression, and the
values are additionally constrained: the shipped network was **trained** against
this quantisation, so they are dictated by the weights. The SIMD kernels that
implement them (`resonance_simd.h`) were written for this project.

The NNUE approach itself originates with **Yu Nasu** (Shogi, 2018) and reached
chess through the Stockfish NNUE effort.

**The lone-king mop-up constants** (`MOPUP_EDGE = 64`, `MOPUP_APPROACH = 16` in
`resonance_net.h`) are carried forward from an earlier tree and have not been
re-derived by measurement in this codebase. Flagged rather than claimed.

## 3. Third-party source

**None vendored in this tree.** No Fathom, no Syzygy probing code (there is no
tablebase support), and no shared NNUE trainer. Every file in `src/` originates
with this project or with the NARC Engine codebase named above — none of it is
copied from another engine. The engine contains no Stockfish source code; the
NNUE *architecture* debt is described in §2. AI coding assistance was used
during development; see §6.

The only external code in a shipped binary is the statically linked C++
runtime — see §5.

## 4. Original to CeylonDemon

- The **Resonance dual-frame architecture** — two feature transformers
  differing only in which king anchors the frame (AEGIS / LANCE), blended by a
  learned per-bucket gate.
- The **Resonance v12 interaction residual** — a bounded rank-8 term coupling
  the AEGIS and LANCE frames, computed in integer arithmetic.
- **Sigma**, the residual `|AEGIS − LANCE|`, exposed as a diagnostic uncertainty
  signal. Sigma-aware search policies remain experimental in 3.3.
- The `.aa` network format and loader; the embedded-network build.
- The training corpus: 400,746,429 self-play positions generated by this
  engine's own `datagen`.

**Network provenance — important.** The Resonance v12 weights embedded in
CeylonDemon 3.3
(`networks/ceylondemon-3.1-resonance-v12-400m-full-scratch-e8.aa`, SHA-256
`38B398F22E792AD4B4B7A79920AEF6B7574011F43E1F6751BFA15B4750CCCE57`) were
trained from random initialization on the corpus above: 396,493,884 training
and 4,252,545 held-out validation positions, epoch 8 selected on validation
loss (`0.010458274903805277`). No teacher network, inherited weights or
third-party game data were used. The inference and quantisation architecture
still follows published Stockfish NNUE practice as acknowledged in §2; the
engine contains no Stockfish source code (§3).

## 5. Toolchain and runtime

Windows binaries are built with **GCC (MinGW-w64, MSYS2 UCRT64)** and statically
link:

- **libstdc++** — GPLv3 with the **GCC Runtime Library Exception**, which
  permits static linking into programs regardless of their licence.
- **MinGW-w64 runtime and winpthreads** — permissive licences (public-domain and
  BSD-style terms); see the MinGW-w64 distribution for full text.
